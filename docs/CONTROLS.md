# SKYFOLD: The Last Flight — Controls

One game, two ways to play. Both use the same save. The in-game **Controls** screen (main menu or pause) shows the same list.

## Laptop (keyboard and mouse)

### On foot in the city

| Action | Key |
| --- | --- |
| Move | W A S D (or arrow keys) |
| Look | Mouse |
| Walk slowly | Hold Left Shift |
| Use, pick up, put down, climb in | E |
| Fold up to the Atelier (at a Fold Station kiosk) | Q |
| Objectives panel | Tab |
| Pause | Esc |

### At the plinth (Architect view)

| Action | Key |
| --- | --- |
| Pick up and drag a piece | Hold left mouse button |
| Turn the held piece a quarter | R |
| Set it down (snaps to a socket if it fits) | Release the left mouse button |
| Orbit around the miniature | Right-drag, or W A S D |
| Zoom | Mouse wheel |
| Fold down into the street | Q |

### In the courier car

| Action | Key |
| --- | --- |
| Accelerate | W (or Up) |
| Brake; hold at a stop to reverse | S (or Down) |
| Steer | A / D (or Left / Right) |
| Parking brake | Space |
| Climb out (car must be stopped) | E |
| Horn | H |
| Chase / hood camera | C |
| Put the car back on the road (if stuck) | Hold R for about a second |

### Developer and event keys

| Action | Key |
| --- | --- |
| Input diagnostics panel | F1 |
| Screenshot (saved to `%USERPROFILE%\AppData\LocalLow\Team Kanban\SKYFOLD\Screenshots`) | F12 |
| Operator: reset the demo (keeps campaign progress) | F5, or Pause → *Operator: reset demo* |

## Meta Quest 3 through Link (Touch / Touch Plus controllers)

### On foot and at the plinth

| Action | Control |
| --- | --- |
| Move (Smooth movement mode) | Left stick |
| Turn (snap by default; smooth is an option) | Right stick left / right |
| Teleport | Hold **A** to aim, release to jump (cancel by pointing at nothing valid) |
| Grab a piece, the power cell or a lever | Grip |
| Use, press buttons, menu pointer | Trigger |
| Fold (at a Fold Station kiosk or the plinth) | **X** |
| Wrist objectives | **Y** |
| Back (menus) | **B** |
| Pause | Left **Menu** button |

The Meta (Oculus) button always stays with the headset.

### Button cards on your hands

The courier gloves cover the real controllers, so each hand carries a small card that lists what its
buttons do right now: at the plinth, on foot, in the car and in menus. The button the current step
needs is lit in teal (Grip to grab the bridge, X to fold, the right trigger to drive, Trigger to
select in a menu). The cards appear when you look at a hand and for a few seconds whenever the
controls change. **Comfort → Button hints on your hands** switches them to *Always* or *Off*.
Pressing **Y** shows the wrist panel with the objective and the full button list.

### In the courier car

| Action | Control |
| --- | --- |
| Steer | Left stick left / right |
| Accelerate | Right trigger |
| Brake; hold at a stop to reverse | Left trigger |
| Climb out (car must be stopped) | **B** |
| Horn | **A** |
| Put the car back on the road (if stuck) | Hold **X** for about a second |
| Objectives / pause | **Y** / Left **Menu** |

Teleport, grab and fold are disabled while you drive. If either controller loses tracking, the car holds still until both are visible again.

## Comfort options (Pause → Comfort, or the main menu)

- **Movement**: Smooth (left stick) or Teleport only (A).
- **Turning**: Snap turns (30°, 45° default, 60°, 90°) or smooth turning (30–150°/s).
- **Walking speed**: 1.0–3.5 m/s.
- **Comfort vignette** on or off, with a strength slider. It narrows the view while you move or drive.
- **Seated play** raises your view. **Set my height** and **Recenter view** recalibrate at any time.
- **Driving**: *Sit in the car* (cockpit, stable horizon, no roll or pitch) or *Remote, from an overlook* (you stand still at a fixed viewpoint and steer the car from there).
- **Guidance**: Full tutorial, Hints only, or Off. The storm timer waits while tutorial steps are on screen.
- **Reduce flashing**: removes the storm's lightning flashes.

Audio & subtitles: master, music, effects, voice and ambience sliders. Subtitles are on by default, in four sizes. Display & mouse (laptop only): window mode, resolution, mouse sensitivity, invert Y and field of view.
